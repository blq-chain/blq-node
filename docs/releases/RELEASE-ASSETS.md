# Release assets

Source files are recorded in [source-manifest-v0.1.0.json](source-manifest-v0.1.0.json)
and [SHA256SUMS-v0.1.0](SHA256SUMS-v0.1.0). Compiled binaries are intentionally
not committed. Build the tagged source with the instructions in the repository
README, then generate and publish a SHA-256 checksum beside every release
binary.
